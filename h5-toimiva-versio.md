## Tiivistelmä  
Getting Started - What is Git?  
-Toisin kuin muut ohjelmat, Git ottaa kuvan tiedostosta ja tallentaa sen, jos se on muuttunut edelliseen verrattuna.  
-Suurin osa gitin toiminnoista tarvitsee vain paikallisia tiedostoja toimiakseen.  
-Git käyttää tarkistussummaa kaikkeen, ennen tallentamista.  -
-On mahdoton muokata tiedostoa tai hakemistoa ilman, että git tietää siitä.  
-On vaikeaa saada Git tekemään mitään peruuttamatonta tai saada sitä poistamaan dataa.  
-Gitissä on kolme pää tilaa, jossa tiedosto voi olla. Modified, Staged ja Committed.  
(Chacon and Starub. 2014.)  

Git komennot  
-git add: Lisää tekemäsi muutokset Staged kohtaan.  
-git commit: Tallentaa tekemäsi muutokset.  
-git pull: Hakee ja yhdistää muutokset etä repositorysta paikalliseen repository.  
-git push: Vie paikalliseen repositoryyn tehdyt muutokset etä repositoryyn.  
(Maddula. 2025.)
